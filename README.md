# SODL-traduction-FR

French translation of the *Shadow of the Demon Lord* core book compendium (`sdlc-1000`) for Foundry VTT, using Babele.

## Content
- Paths: 84 names
- Talents: 269 names and descriptions
- Spells: 339 names, descriptions and fields (target, area, duration, triggered, sacrifice…)

## Requirements
- Foundry VTT v13
- Babele
- The official `sdlc-1000` module

## Installation
Place this folder in Foundry's `Data/modules/`, then enable the module and Babele in your world.

## Note
Private use only: the translated texts come from the French edition of the book.

- [Babele](https://foundryvtt.com/packages/babele)

## Installation

Download `sodl-traduction-fr.zip` from the latest release, unzip it into Foundry's `Data/modules/SODL-traduction-FR/`, then enable the module and Babele in your world.

## Release

Run the **Release SODL Traduction FR** workflow from the Actions tab and pick `patch`, `minor` or `major`. It bumps the version in `module.json`, commits it, and publishes a GitHub release with `sodl-traduction-fr.zip` and `module.json`.
